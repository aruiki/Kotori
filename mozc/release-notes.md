**Kotori日本語入力**の Windows 版です(ベータ版、未署名)。Mozc(Google 日本語入力のオープンソース版)を土台に、
AI が文脈を読んで候補を選び直します。AI のモデルと GPU の実行環境を同梱しているので、MSI を実行するだけで使えます。

## この版の変更

- **上書きインストールで入れ替わるようになった**: 前の版の上に入れても古いファイルが残っていた。v0.3.0-beta.5 では
  版の番号の上げ方に誤りがあり、まだ入れ替わらなかった。この版で直し、公開した MSI の版も確かめている。
- **入力中の AI の予測が邪魔になりにくくなった**: 別の文へ脱線した予測(「「日本語教育」など)、読みを写しただけの
  カタカナ、1 文字だけの続きを出さない。Tab で AI が先頭に並べる予測を 4 つから 2 つにした。入力中の候補の当たりが
  増え(29 問中 11〜13 → 15)、外れの候補が減った。
- **Unreal(最高設定)が High より正確になった**: 大きい変換用 AI(zenz-v2.5-medium)の候補も合わせて選ぶ。
  AJIMEE-Bench 92.5% → 93.0%。速い GPU 向け。
- **VRAM を約 170 MB 減らした**(Standard・High、RTX 3060 で 1.66 GB → 1.49 GB)。速さと正確さは変わらない。

前の版(v0.3.0-beta.5)の主な変更: ノート PC で固まらない、GPU のない PC 向けの新しい Low、GPU の負荷を約 3 割減、
設定画面の文字が消える不具合の修正、AI の状態の表示、AI が作った文の一部だけを選び直せる。

変換の正確さ(前の文あり):

| 品質 | AJIMEE-Bench | 日常の文 81 問 |
| --- | ---: | ---: |
| Mozc 単体 | 51.0% | 80.2% |
| Low(GPU のない PC) | 88.0% | 97.5% |
| **Standard(既定)** | **91.5%** | **97.5%** |
| High | 92.5% | 97.5% |
| Unreal | 93.0% | 97.5% |

## 入れ方

1. 下の `Kotori64.msi` をダウンロードして、ダブルクリックする(管理者の確認で「はい」)。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
2. 入力方式に **Kotori日本語入力** が加わる。Windows キー + Space で切り替え、半角/全角キーでオン/オフ。
3. 設定はデスクトップの「Kotori日本語入力の設定」から。「AI 変換」タブで品質を選べる。

v0.3.0-beta.5 以前が入っているときは、一度アンインストールしてから入れてください(この版からは上書きで
入れ替わります)。外すときは、設定 →「アプリ」→「インストールされているアプリ」で Kotori日本語入力 を
アンインストールする。

## 必要な環境

Windows 10 1809 以降(64 bit)。専用の GPU(Vulkan 対応、VRAM 3 GB 以上)があれば Standard 以上が使えます。
GPU がなくても Low で動きます。ディスク 1.7 GB。
