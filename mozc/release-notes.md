**Kotori日本語入力**の Windows 版、**v1.1 のリリース候補**です(まだコード署名をしていません)。Mozc(Google 日本語入力の
オープンソース版)を土台に、AI が文脈を読んで候補を選び直します。AI のモデルと GPU の実行環境を同梱しているので、MSI を実行するだけで使えます。

入れるときに Windows の警告が出たら、下の「入れ方」を見てください。入力できない、落ちる、候補の出方がおかしいなどがあれば、
設定の「診断情報を書き出す...」で保存したファイルを添えて [Issues](https://github.com/aruiki/KotoriIME-japanese-/issues/new/choose)
で知らせてください。

## この版の変更(v1.0.0 から)

- **手を止めると、Space を押す前に AI の変換が出る**: 打ち終わって手を止めると(0.2 秒ほど。GPU のない PC は 0.5 秒ほど)、
  入力中の候補の先頭が、Space を押したときと同じ AI の変換に変わります(例: 「彼は公園で公園をした」→「彼は公園で**公演**をした」、
  「明日の会議は従事からです」→「明日の会議は**１０時**からです」)。Space を押すと、そのまま同じ変換になります(待ち時間 1〜2 ms)。
  これまでは、手を止めても Mozc の変換が出たままで、Space を押してから AI の変換に変わっていました。
- **Tab の予測も、手を止めると出る**: 裏で作った文の続きの予測(Tab と同じもの)が、次のキーを押さなくても候補に並びます。

変換の正確さ(前の文あり):

| 品質 | AJIMEE-Bench | 日常の文 81 問 |
| --- | ---: | ---: |
| Mozc 単体 | 51.0% | 80.2% |
| Low(GPU のない PC、CPU で測定) | 83.0% | 97.5% |
| **Standard(既定)** | **91.5%** | **97.5%** |
| High | 92.5% | 97.5% |
| Unreal | 93.0% | 97.5% |

## 入れ方

1. 下の `Kotori64.msi` をダウンロードして、ダブルクリックする(管理者の確認で「はい」)。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」(署名を付けるまでの間、出ます)。
2. 入力方式に **Kotori日本語入力** が加わる。Windows キー + Space で切り替え、半角/全角キーでオン/オフ。
3. 設定はデスクトップの「Kotori日本語入力の設定」から。「AI 変換」タブで品質を選べる。

v0.3.0-beta.6 以降が入っていれば、上書きで入れ替わります(設定・学習・辞書は残ります)。それより前の版は、
一度アンインストールしてから入れてください。

## 必要な環境

Windows 10 1809 以降(64 bit)。専用の GPU(Vulkan 対応、VRAM 3 GB 以上)があれば Standard 以上が使えます。
GPU がなくても Low で動きます。ディスク 1.7 GB。
