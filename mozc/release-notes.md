**Kotori日本語入力**の Windows 版です(ベータ版、未署名)。Mozc(Google 日本語入力のオープンソース版)を土台に、
AI が文脈を読んで候補を選び直します。AI のモデルと GPU の実行環境を同梱しているので、MSI を実行するだけで使えます。

## この版の変更

- **変換の正確さが上がった**: AI が文全体で選んだ答えを、後の処理が別の候補に戻していた不具合を直した
  (「東京特許許可局協急遽休暇」→「今日急遽休暇」)。LLM の重みを調整し、「速く起きる」「熱い本」のような
  取り違えも減った。
- **Tab の予測が速くなった**: 入力中に裏で作った予測を使うので、手を止めてから Tab を押すと約 0.04 秒で出る
  (以前は約 0.5 秒)。
- **長い文でも固まらない**: 250 文字ほどの変換が 5〜8 秒かかっていたのを、最大 0.6 秒ほどに。
- **設定画面を作り直した**: 品質ごとの速さと正確さ、この PC の GPU と VRAM、おすすめの品質を表示する。
  「入力中に AI の予測を出す」を切り替えられる。設定アプリのアイコンが Mozc のままだったのも直した。

変換の正確さ(前の文あり):

| 品質 | AJIMEE-Bench | 日常の文 81 問 |
| --- | ---: | ---: |
| Mozc 単体 | 51.0% | 80.2% |
| Low | 86.5% | 93.8% |
| **Standard(既定)** | **91.5%** | **97.5%** |
| High | 92.5% | 97.5% |

## 入れ方

1. 下の `Kotori64.msi` をダウンロードして、ダブルクリックする(管理者の確認で「はい」)。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
2. 入力方式に **Kotori日本語入力** が加わる。Windows キー + Space で切り替え、半角/全角キーでオン/オフ。
3. 設定はデスクトップの「Kotori日本語入力の設定」から。「AI 変換」タブで品質を選べる。

前の版から上書きでインストールできます。外すときは、設定 →「アプリ」→「インストールされているアプリ」で
Kotori日本語入力 をアンインストールする。

## 必要な環境

Windows 10 1809 以降(64 bit)。GPU(Vulkan 対応、VRAM 2 GB 以上)があれば Standard 以上が使えます。
GPU がなくても品質 Low で動きます。ディスク 1.3 GB。
