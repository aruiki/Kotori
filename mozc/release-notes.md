Kotori の Windows 版です(Mozc ベース、開発中のベータ版、未署名)。

Mozc(google/mozc、BSD-3-Clause)をベースにし、名前と識別子を Kotori に変えたものです。
半角/全角キーでのオン/オフ、候補ウィンドウ、入力モードの表示、設定画面、ユーザー辞書、学習、
予測入力は Mozc のものがそのまま動きます。AI(LM)による並べ替えはまだ入っていません(次の段階で入れます)。

## 入れ方

1. 下の `Kotori64.msi` をダウンロードして、ダブルクリックする(管理者の確認で「はい」)。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
2. 設定 →「時刻と言語」→「言語と地域」→「日本語」の「…」→「言語のオプション」→「キーボードの追加」で
   **Kotori** を選ぶ。
3. Windows キー + Space で Kotori に切り替える。半角/全角キーでオン/オフ。

外すときは、設定 →「アプリ」→「インストールされているアプリ」で Kotori をアンインストールする。
以前の Kotori(zip 版、v0.1.0-beta.x)を入れていた場合は、先にその uninstall.cmd で外してください。
本家の Mozc や Google 日本語入力とは別のものとして入るので、並べて使えます。
