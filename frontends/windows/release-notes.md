Kotori の Windows 版(開発中のベータ版、未署名)です。

## 入れ方

1. 下の `Kotori-*-windows.zip` をダウンロードして展開する(右クリック →「すべて展開」)。
2. 展開したフォルダの **install.cmd** をダブルクリックし、管理者の確認で「はい」を選ぶ。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
3. 設定 →「時刻と言語」→「言語と地域」→「日本語」の「…」→「言語のオプション」→「キーボードの追加」で Kotori を選ぶ。
4. Windows キー + Space で Kotori に切り替える。

外すときは **uninstall.cmd** をダブルクリックする。詳しくは zip の `README.txt` を見てください。

## できること

ローマ字入力、変換(Space)、次の候補、文節の移動と伸縮(Shift + ← / →)、F6〜F10 の文字種変換、入力中のカーソル移動、確定・取消、下線の表示、パスワード欄での直接入力。
AI のモデル(zenz-v2.5-small)を置くと、変換のあと候補が LM の結果に差し替わります(モデルは同梱していません)。

## 今の制限

- 候補ウィンドウはまだ出ません(候補は入力中の文字の中で切り替わる)。
- 予測入力、学習、ユーザー辞書、設定画面はまだありません。
- 動作は CI の Windows でのビルドと登録までしか確かめていません。問題は Issue に書いてください。

同梱の辞書(Mozc 由来)と部品のライセンスは zip の `THIRD_PARTY_NOTICES.txt` にあります。
`.sha256` は zip の SHA-256 です。
