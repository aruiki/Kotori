# Kotori日本語入力 使い方と困ったとき

Kotori日本語入力(以下 Kotori)を使う人のための案内です。開発の文書は [README](../README.md) の「開発者向け」から。

- [入れる](#入れる) ・ [使う](#使う) ・ [設定](#設定) ・ [更新する](#更新する) ・ [外す](#外す)
- [データとプライバシー](#データとプライバシー) ・ [困ったとき](#困ったとき) ・ [既知の制限](#既知の制限) ・ [報告する](#報告する)

## 入れる

1. [Releases](https://github.com/aruiki/KotoriIME-japanese-/releases/latest) から `Kotori64.msi` をダウンロードして実行します
   (管理者の確認で「はい」)。
2. 入力方式に **Kotori日本語入力** が加わります。
3. 設定はデスクトップとスタートメニューの「Kotori日本語入力の設定」から開けます。

必要な環境: Windows 10 1809 以降または Windows 11(64 bit)、メモリ 8 GB 以上、ディスク 1.7 GB。
GPU はなくても動きます(専用 GPU、Vulkan 対応、VRAM 3 GB 以上があれば Standard 以上の品質になります)。

ダウンロードした MSI が壊れていないかは、同じリリースの `Kotori64.msi.sha256` と比べて確かめられます
(PowerShell で `Get-FileHash Kotori64.msi`)。

## 使う

操作は Mozc(Google 日本語入力)と同じです。

| したいこと | キー |
| --- | --- |
| 入力方式を切り替える | Windows + Space |
| 日本語入力のオン・オフ | 半角/全角 |
| 変換・次の候補 | Space |
| 確定 | Enter |
| 文節の区切りを伸ばす・縮める | Shift + ← / → |
| 前後の文節に移る | ← / → |
| AI の予測(文の続き)を選ぶ | Tab(候補に「AI」と付いているもの) |
| 変換をやめて読みに戻す | Esc |

- 変換すると、AI が前後の文脈を読んで候補を選び直します。AI が時間内に終わらないときは、待たせずに Mozc の結果を出します。
- 入力している間、AI が文の続きを裏で考えます。手を止めて Tab を押すと選べます。
- ユーザー辞書に登録した語は、AI が書き換えません。辞書は設定の「辞書」から開けます。
- パスワードの欄では日本語入力になりません。

## 設定

設定の「AI 変換」タブ:

| 項目 | 中身 |
| --- | --- |
| 品質 | Low / **Standard(既定)** / High / Unreal。上ほど軽く、下ほど正確で重い。GPU のない PC はどれを選んでも CPU 向けの設定で動きます |
| AI の状態 | 実際に動いている AI と使っている GPU。「動いています」「モデルを読み込んでいます」「休んでいます」「動いていません(理由)」 |
| 入力中の AI 予測 | 入力中に文の続きを出すか |
| AI モデル | 使うモデルのファイル(ふつうは変えません) |

品質の選び方: まず Standard のまま使い、ゲーム中などに重いと感じたら Low に。速い GPU があって精度を上げたいときは High。

## 更新する

新しい版の `Kotori64.msi` を、今の版の上にそのまま入れます(v0.3.0-beta.6 以降)。設定・学習・ユーザー辞書は残ります。
入力中のアプリがあると再起動を求められることがあります。

Kotori はインターネットにつながらないので、新しい版が出ても知らせません。
[Releases](https://github.com/aruiki/KotoriIME-japanese-/releases) を見るか、GitHub でリポジトリの「Watch」→「Custom」→「Releases」を選ぶと通知が届きます。

前の版に戻すときは、一度アンインストールしてから前の版の MSI を入れます(上書きで古い版には戻せません)。

## 外す

Windows の「設定」→「アプリ」→「インストールされているアプリ」で **Kotori日本語入力** をアンインストールします。

アンインストールしても、次のデータは残ります(入れ直したときに引き継ぐため)。すべて消すときは、アンインストールの後に
このフォルダを削除します。

```
%USERPROFILE%\AppData\LocalLow\Kotori
```

## データとプライバシー

- **Kotori はインターネットに接続しません。** 変換も AI も PC の中だけで動き、入力した文字を外に送りません。
  利用状況の送信(テレメトリ)や、自動の不具合報告もありません。
- PC に保存するもの(`%USERPROFILE%\AppData\LocalLow\Kotori`):

  | ファイル | 中身 |
  | --- | --- |
  | `config1.db` | 設定 |
  | `user_dictionary.db` | ユーザー辞書 |
  | `history.db`、`segment.db`、`boundary.db` など | 変換の学習(よく選ぶ候補、文節の区切り)。Mozc と同じ |
  | `kotori_ai_status.txt` | AI の状態(GPU の名前、使っているモデル)。設定画面の表示に使う |

- AI が文の続きを予測するために覚えておく内容は、メモリの中だけに置き、ファイルには書きません。
  シークレットモード(ブラウザのプライベートウィンドウなど)では予測を作りません。
- 学習を消すときは、設定の「辞書」タブの「学習履歴のクリア」を使います。
- ログに入力した文字・読み・候補は書きません。不具合の報告にも、入力した文の中身は要りません。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「Windows によって PC が保護されました」と出て入れられない | 「詳細情報」→「実行」。署名のない版で出ます |
| 入力方式の一覧に出ない | サインアウトしてサインインし直す。「設定」→「時刻と言語」→「言語と地域」→ 日本語の「…」→「言語のオプション」→ キーボードに Kotori日本語入力 があるか見る |
| AI が動いていない(候補に AI の選び直しが効かない) | 設定の「AI 変換」タブの「AI の状態」を見る。「動いていません」なら理由が出ます。日本語を一度入力すると表示が更新されます |
| 変換が遅い・入力が固まる | 品質を Low にする。GPU のない PC では自動で CPU 向けになります。直らなければ[報告](#報告する)してください |
| ゲーム中に GPU のメモリが足りない | 10 分入力がなければ AI を外して空けます。すぐに空けたいときは品質を Low に |
| 起動して最初の変換で AI が効かない | モデルの読み込み中は Mozc の結果を出します。数秒で AI が使えるようになります |
| ある アプリでだけ入力できない | アプリ名と版を書いて[報告](#報告する)してください。その間は Windows + Space でほかの IME に切り替えます |
| 元の IME(Microsoft IME など)に戻したい | Windows + Space で切り替える。Kotori を既定にしたくないときは、言語のオプションで並び順を変えるか、Kotori を削除する |

## 既知の制限

- **GPU のない PC で長い文を打ってすぐ Space を押すと**、AI が間に合わず Mozc の結果になることがあります
  (少し待ってから Space を押すと AI の結果になります)。
- 内蔵 GPU(CPU に付いている GPU)は AI に使いません。反応が遅く、入力が止まるためです。
- 64 bit の Windows(x64)だけに対応しています。ARM 版の Windows には対応していません。
- 打ち間違いの補正(「ありがとうごさいます」→「ありがとうございます」)は、GPU があり品質が Standard 以上のときだけ、
  1 か所の打ち間違いに効きます。

## 報告する

[Issues](https://github.com/aruiki/KotoriIME-japanese-/issues/new/choose) から、種類(不具合・誤変換・要望)を選んで書いてください。

- 不具合の報告には、Kotori の版(入れた MSI のリリース名。「設定」→「アプリ」に出る版でもかまいません)、Windows の版、GPU、品質、起きたアプリと手順を書いてください。
- **入力した文の中身は、誤変換の報告で必要な読みと結果だけにしてください。** パスワードや個人の情報を貼らないでください。
- セキュリティの問題(脆弱性)は Issue に書かず、[SECURITY.md](../SECURITY.md) の方法で知らせてください。
