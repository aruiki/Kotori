# 受け入れ試験の確認表(Windows 版の MSI、Mozc 版)

リリース候補の MSI を配る前に、実機で確かめる項目(docs/IMPROVEMENT_PROPOSALS.md の案 05)。変換器だけの
試験(`mozc/tools/` の評価・負荷試験)では分からない、入力不能・表示・更新の問題を拾う。自動化しにくい操作は
この表に結果(OK / NG と症状)を書き、PR かリリースの Issue に貼る。旧 Rust 版(`frontends/windows`)の試験とは分ける。

記録する前提: MSI の版(`mozc_server.exe` のファイルの版)、Windows の版、CPU・GPU・ドライバー、
表示の拡大率、ダーク / ライト、設定の品質。

## 1. 入れる・更新する・外す

| # | 操作 | 確かめること |
| --- | --- | --- |
| 1-1 | 何も入っていない PC に入れる | 言語の一覧に「Kotori日本語入力」が出る。デスクトップとスタートメニューに設定のショートカット |
| 1-2 | 前のリリースの上に上書きで入れる | `C:\Program Files (x86)\Kotori` の exe・dll の版と日時が新しくなる(docs/tasks/done/22)。設定・辞書・学習が残る |
| 1-3 | 入力中のアプリを開いたまま上書きで入れる | 再起動を求められたら、再起動後に新しい版で入力できる |
| 1-4 | アンインストール → 入れ直す | 言語の一覧から消え、入れ直すと戻る。`%USERPROFILE%\AppData\LocalLow\Kotori` の扱いを記録する |
| 1-5 | 前の版に戻す | アンインストールしてから前の MSI を入れて入力できる(上書きで古い版には戻せない) |

## 2. 入力(アプリごと)

メモ帳、ブラウザ(Edge / Chrome のフォーム)、Word / Excel、VS Code、Windows Terminal、32 bit のアプリ、
管理者として動くアプリ、ストアアプリで、次を試す。

| # | 操作 | 確かめること |
| --- | --- | --- |
| 2-1 | 半角/全角、Windows + Space | オン・オフと入力方式の切り替え。タスクバーのモード表示 |
| 2-2 | 打つ → Space → Enter | 変換・確定。候補ウィンドウの位置 |
| 2-3 | Shift + ←/→、←/→、候補の選び直し | 文節の伸縮と移動 |
| 2-4 | 打って Tab | AI の予測が出る(品質 Standard 以上、GPU あり)。出るまでの待ち |
| 2-5 | パスワード欄 | 日本語入力にならない |
| 2-6 | フォーカスを別のアプリ・欄に移す | 未確定の文字が残らない・消えない。前の欄の文脈を持ち越さない |
| 2-7 | 複数の画面、画面の端 | 候補ウィンドウが画面の外に出ない |

## 3. 端末と設定

| # | 条件 | 確かめること |
| --- | --- | --- |
| 3-1 | GPU のない PC・内蔵 GPU だけの PC | 10 文字ほど打ってすぐ Space で固まらない(docs/adr/0024)。設定画面の「AI の状態」が CPU で動作 |
| 3-2 | 起動直後(モデルの読み込み中) | 打って Space で固まらない。AI の状態が「読み込んでいます」→「動いています」 |
| 3-3 | 設定で品質・AI モデルを変える | 変えた直後の予測・変換が新しい設定のもの(docs/adr/0025) |
| 3-4 | シークレットモード | AI の予測が出ず、前の予測が残らない |
| 3-5 | 設定画面: ダーク / ライト、拡大 100・150・200%、Tab キーだけの操作、ナレーター | ボタンと「適用」の文字が見える。表示が崩れない。キーボードだけで設定できる |
