# 0034. しばらく入力がなければモデルを外して VRAM を空ける

- 状態: 採用
- 日付: 2026-10-01
- 関係: docs/adr/0024(負荷を下げる)、0026(AI の状態の表示)、作業カード 37

## 背景

mozc_server は起動するとモデル(Standard で zenz-v2.5-small と TinySwallow-1.5B、VRAM 約 1.5 GB)を GPU に載せ、
入力していない間も載せたままにしていた。日本語を打たずにゲームや動画の編集をしている間も、VRAM を 1.5 GB 使い続ける。
GPU のない PC では、同じだけのメモリ(RAM)を使い続ける。

## 決めたこと

- 最後の要求(打鍵・変換・Tab)から一定の時間(既定 10 分、`KOTORI_LM_IDLE_UNLOAD` 秒、0 で外さない)が
  経ったら、裏のスレッドがモデルをすべて外す。覚えておいた予測(入力した文字を含む)と先回りの変換の結果も捨てる。
  確かめるのは 30 秒ごと。要求の最中(ロックが取れないとき)は外さない。
- 外した後の最初の要求で、裏で読み込み直す(起動時と同じ。`RequestLoad`)。読み込みの間の変換は待たずに
  AI なし(Mozc の結果)で出す(docs/adr/0024)。
- 設定画面の AI の状態に「休んでいます(…次に入力すると読み込みます)」と出す(状態 `sleep`)。
- 評価(`KOTORI_LM_PRELOAD=0`)では外さない。

10 分にしたのは、読み込み直しが GPU で 0.4〜0.7 秒(`docs/PERFORMANCE.md` の最初の変換)かかり、打ち始めてすぐ
Space を押すとその 1 回だけ AI なしになるため。会話や文書の途中の短い中断(数分)では外さない。

## 結果(RTX 3060、`mozc/tools/idle_test.py --idle 40`)

| | GPU 全体の VRAM |
| --- | ---: |
| converter_main を起動する前 | 1592 MB |
| 読み込んだ後 | 3047 MB |
| 入力がなくなってから 60 秒後(外した後) | **1600 MB** |
| 入力し直して 3 秒後(読み込み直した後) | 3059 MB |

- 外した後の最初の打鍵は 3 ms、すぐの変換は AI なし(2 ms)、3 秒後の変換は AI あり(60 ms)。
- GPU のない PC(`KOTORI_LM_DEVICE=cpu`): 3 秒後の変換は AI あり(247 ms)。
- 負荷試験・単体テスト・入力中の AI の稼働率(41.5%)は変わらない。

## 採らなかった案

- 外さない(前のまま): VRAM を使い続ける。
- 予測の LLM だけを外す: 変換(Standard 以上)でも LLM を使うので、外すと変換の精度が下がる。
- 設定画面で時間を選べるようにする: まずは既定の 10 分で様子を見る。要望があれば設定に出す。
