# 0028: 設定画面をハイコントラストとキーボード操作に合わせる

- 状態: 採用
- 日付: 2026-09-30
- 関係: docs/adr/0017、0022、0024、docs/IMPROVEMENT_PROPOSALS.md の案 14

## 問題

- docs/adr/0024 で、ダークモードでボタンの文字が消えないように、アプリの配色を明るく固定した。このままでは、
  Windows のハイコントラストを使う人にも Kotori の明るい配色とスタイルが出て、読みにくくなる。
- 設定画面のスタイルでボタンなどの見た目を変えているため、Tab キーで移動したときのフォーカスが見えにくい。

## 決定

- Windows のハイコントラスト(`SPI_GETHIGHCONTRAST` の `HCF_HIGHCONTRASTON`)が有効なら、配色の固定
  (`GuiUtil::InitQt`)と設定画面のスタイルを当てず、Windows の配色に従う。
- スタイルに、フォーカスがあるボタン(青い 2px の枠。既定のボタンは黒い枠)、チェックボックス・ラジオボタン
  (薄い青の背景)、タブ(青い枠)を足す。

## 確認

- ふだんの設定画面で、Tab キーでフォーカスを移すと枠が見える(画像で確認)。
- ハイコントラストでの見た目は、実機で確かめる(docs/ACCEPTANCE.md の 3-5)。
