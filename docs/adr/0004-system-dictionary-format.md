# 0004: システム辞書のバイナリ形式

- 状態: 採用
- 日付: 2026-09-28

## 背景

5.3 は、読みをキーとするダブル配列トライ(共通接頭辞検索と予測検索)、Mozc 品詞体系の
連接コスト行列(i16)、ヘッダにマジック `KTRD`・形式バージョン・SHA-256・セクション
オフセットを持つリトルエンディアンの形式を求める。細部は決まっていない。

## 決定

- ヘッダ 64 バイト + セクション表(5 × (オフセット u64, 長さ u64))。SHA-256 はヘッダと
  セクション表より後ろの全バイトに対して計算する。各セクションは 8 バイト境界に揃える。
- セクションは順に、トライ、読みの表、エントリ、文字列、連接行列。
- トライは `yada`(ダブル配列、MSRV 1.58、依存なし)。値は読みの表の添字。
- 予測検索はトライを辿らず、辞書順に並んだ読みの表を二分探索する。表は共通接頭辞検索の
  結果から読みを引くのにも使うので、追加のセクションは要らない。
- エントリは 16 バイト固定長(表記の位置と長さ、lid、rid、コスト、属性フラグ)。
  同じ読みのエントリは連続し、コストの昇順に並ぶ。
- 文字列は UTF-8 を連結し、同じ文字列は1回だけ置く。
- 構築時にエントリを (読み, コスト, lid, rid, 表記, フラグ) で整列し、完全な重複を除く。
  入力の順序によらず同じバイト列になる(REQ-5-5)。
- 読み込み時に、マジック・バージョン・SHA-256・各セクションの範囲・全参照の範囲と
  UTF-8・トライと読みの表の対応を検証する。以後の検索は壊れたデータでパニックしない。
