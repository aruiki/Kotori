# 0022: 設定の「AI 変換」タブを使う人の言葉で作り直す

- 状態: 採用
- 日付: 2026-09-30
- 関係: docs/adr/0017(Fluent 2 風の設定画面)、0019

## 問題

設定アプリ(`mozc_tool.exe --mode=config_dialog`)を開いて、ウィンドウだけを画像にして確かめた。

- タイトルバーのアイコンが Mozc の橙の「あ」のままだった。`mozc_tool` の資源(.rc)がアイコンの
  ファイルを入力として宣言しておらず、アイコンを差し替えても前のビルド結果が使われていた。
- 説明が開発者向けだった(「AI(zenz)で変換候補を並べ替える」「zenz-v2.5-xsmall-q8_0.gguf を
  インストール先に置く」)。
- どの品質を選べばよいか、GPU を使えるかが画面から分からなかった。
- 入力中の AI 予測を切る方法がなかった。

## 決定

- `gui/tool/BUILD.bazel` の `mozc_tool_win32_resource` に `//data/images/win:product_icon.ico` を入れる。
- 「AI 変換」タブを、Windows 11 の設定アプリのように見出しと説明の付いたカード 3 枚にする。
  1. 変換: 「AI 変換を使う」、品質(Low / Standard(おすすめ)/ High / Unreal)。選んだ品質の説明
     (速さと正確さ)をその場で出す。この PC の GPU の名前と VRAM を DXGI で調べて出し、VRAM が
     2 GB 未満か GPU がなければ Low をすすめる。
  2. 予測: 「入力中に AI の予測を出す」(新しい設定 `kotori_lm_predict`、既定は有効)。切ると、
     入力中の候補と Tab の AI 予測を出さない(Mozc の予測は出る)。
  3. 詳細: AI モデル(自動 / zenz のみ / zenz + LLM)と LLM のファイル。
- 品質の説明は、設定を読み込んだときにも更新する(同じ番号でも変更の知らせが出るよう、一度 -1 にする)。

変換の処理は変えていないので、精度と速さは変わらない。
