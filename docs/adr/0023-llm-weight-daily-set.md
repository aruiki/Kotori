# 0023: 日常の文の評価セットを作り、LLM の重みを 0.7 にする

- 状態: 採用
- 日付: 2026-09-30
- 関係: docs/adr/0016、0020

## 問題

AJIMEE-Bench は百科事典のような文が多い。メールやチャットの文で Mozc 単体と比べると、LLM が
文脈のない短い文で強く逆を推し、zenz の正しい選択を覆すことがあった。

- 「はやくおきる」: zenz は「早く」、LLM が「速く」を推して「速く起きる」。
- 「あついほん」: 「熱い本」(正しくは「厚い本」)。

## 決定

- 日常の文 81 問の評価セット `eval/sets/kotori-daily.json` を作る。メール・チャット・仕事の連絡、
  同音異義語(機会/機械、計る/量る/図る、早く/速く、暑い/熱い/厚い、地震/自信 など)。
  表記の揺れ(子供/子ども、10時/１０時、ご飯/ごはん など)は正解に含める。
- 点数 = zenz の log P + λ × LLM の log P の λ を 1.0 から 0.7 にする。0.5、0.7、1.0、1.3 を
  比べて 0.7 が最もよかった(ほかのセットは変わらない)。

## 評価(前の文あり、Acc@1)

| | AJIMEE | 慣用句 | ニュアンス | 日常 |
| --- | --- | --- | --- | --- |
| Mozc 単体 | 51.0% | 88.0% | 55.0% | 80.2% |
| Low | 86.5% | 92.0% | 85.0% | 93.8% |
| Standard(λ 1.0 → 0.7) | 91.5% → 91.5% | 96.0% → 96.0% | 85.0% → 85.0% | 96.3% → **97.5%** |
| High(λ 1.0 → 0.7) | 92.5% → 92.5% | 96.0% → 96.0% | 85.0% → 85.0% | 96.3% → **97.5%** |

日常のセットは λ を選ぶのにも使ったので、次に λ を変えるときは別の文で確かめる。
