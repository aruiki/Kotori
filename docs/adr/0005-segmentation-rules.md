# 0005: 文節区切りの品詞規則

- 状態: 採用
- 日付: 2026-09-28

## 背景

5.5 は文節を「自立語1つ + 後続の付属語(助詞・助動詞・接尾辞)」とし、品詞ルール表で
判定するよう求める(Mozc のセグメンタ規則を参考に独自に定義)。品詞は Mozc の id.def
(IPAdic 系の品詞名)を使う。

## 決定

id.def の品詞名の第1・第2要素で、各文脈 ID を3つに分類し、辞書の品詞分類セクションに
入れる(`kotori_dictc::classify_pos`)。

| 分類 | 品詞 | 文節での扱い |
| --- | --- | --- |
| 付属語 | 助詞、助動詞、`*,接尾`、`動詞,非自立`、`形容詞,非自立`、`記号,句点/読点/括弧閉` | 前の文節につなげる |
| 接頭辞 | 接頭詞、`記号,括弧開` | 次の語と同じ文節にする |
| サ変名詞 | `名詞,サ変接続` | 自立語として新しい文節を始める |
| サ変動詞 | `動詞,自立` のうち活用型が `サ変・スル` | 直前がサ変名詞ならその文節につなげ、そうでなければ新しい文節を始める |
| 自立語 | 上記以外(未知語を含む) | 新しい文節を始める |

- `動詞,非自立`(「ている」の「いる」など)と `形容詞,非自立`(「てほしい」の「ほしい」など)は
  前の語に続くので付属語とした。
- `名詞,非自立`(「こと」「の」など)は、単独で文節を作る用法があるため自立語のままにした。
  区切りが不自然な例が評価で見つかれば、ここを見直す。
- 文の先頭の付属語は、それだけで文節を始める。
- 「する」は Mozc の品詞では自立語なので、分類しないと「帰社 | した」に分かれる。一方で常に
  付属語にすると「私は | する」の「する」が前につながる。そこでサ変名詞の直後だけつなげる
  (「帰社した」「勉強する」、「会議を | します」「それ | してください」)。
- 数字が続くノードは1つの文節にまとめる(特殊変換のため、#20)。

## 影響

- 辞書の形式バージョンを 2 にした(docs/adr/0004)。
