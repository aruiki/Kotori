# 0020: 文全体で選んだ文を、文節ごとの見直しで上書きしない

- 状態: 採用
- 日付: 2026-09-30
- 関係: docs/adr/0015、0016、0019

## 問題

「とうきょうとっきょきょかきょくきょうきゅうきょきゅうか」で、文全体の選択(zenz + LLM)は
「東京特許許可局今日急遽休暇」を選んでいたのに、出力は「東京特許許可局協急遽休暇」だった。

文全体で選んだ文が今の区切りに合うと、各文節の先頭をその文にする(`ApplyBest`)。そのあと、文節ごとの
見直し(`RewriteEachSegment`、zenz だけで採点)がもう一度並べ替え、LLM も見て決めた先頭を戻していた。
先頭がすでに選んだ文と同じときは「合った」ことも伝わらず、文節ごとの見直しが自由に上書きしていた。

## 決定

- `ApplyBest` は「区切りが合ったか」と「入れ替えたか」を分けて返す。
- 区切りが合ったときは、文節ごとの見直しで先頭を動かさず、2 番目以降だけを並べる。

あわせて、生成した文の足切りを強めた(LLM を使わない Low で効く)。

- 小書きのかな(ゃ・ョ など)が、かなでない文字のすぐ後に来る生成を除く(「供給機ョ休暇」)。
- 読みを写しただけの生成の判定(0019 の 6 章)に、カタカナも数える(「キョウキュウキョキュウカ」)。
- LLM を使わないときは、生成した文の点数から 0.5 を引く(同じくらいならラティスの表記を選ぶ)。
  0、0.5、1、2、3 を比べて 0.5 が最もよかった。LLM を使うときは 0(1 以上で下がった)。
