# 32: 内蔵 GPU で zenz だけを動かす案を実機で測る

- 仕様: docs/adr/0024 の「今後」
- 前提: 実機(内蔵 GPU だけのノート PC)の結果
- 規模の目安: 計測の道具 50 行、判断によってはパッチ 50 行

## 目的
今は内蔵 GPU を AI に使わない(休止からの立ち上がりとメモリの共有で、細かく何度も呼ぶ使い方に向かない)。
zenz(小さい)だけなら内蔵 GPU の方が CPU より速いかを、実機で確かめる。

## 手順
1. 内蔵 GPU のノート PC で `perf_table.py` と `space_latency.py` を、CPU(今の既定)と内蔵 GPU
   (`KOTORI_LM_DEVICE` に内蔵 GPU を選ぶ値を足す)で比べる。
2. 内蔵 GPU の方が明らかに速く、固まらなければ、条件付きで使う。そうでなければ今のままにして ADR に記録する。

## 完了条件
- [ ] 実機の数値を docs/PERFORMANCE.md に足す
- [ ] 使う・使わないの判断を ADR に書く
