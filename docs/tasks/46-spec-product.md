# 46: SPEC を製品版の前提に改訂する(承認待ちの PR)

- 仕様: SPEC 1.1・1.2・2.3・16 章・18.7・19.2、docs/adr/0037 の G7
- 前提: #113(Mozc 版での読み替え)。その上に積む
- 規模の目安: SPEC 80 行

## 目的
SPEC は「開発者本人が私用で使うベータ。一般配布・署名・MSI・公開パッケージは非目標」のまま。製品版の配布は
この非目標に当たるので、メンテナの承認を得て改訂する(`AGENTS.md`: SPEC の変更は承認のある PR でのみ)。

## 手順
1. 1.1・1.2: 利用者を「Windows 10 / 11 の一般の利用者」、署名・配布を「署名した MSI を GitHub Releases(のちに winget)」に。
2. 2.3: 非目標から「コード署名、MSI インストーラ、winget 等での公開配布」を外す。
3. 16 章: 16.2 を MSI の入れ方・上書き・アンインストールに、16.3 を docs/adr/0037 の段階(beta / rc / 正式、1.0.x)と
   「自動更新は持たない」に。19.2 の「公開配布へ進む場合の署名手段とライセンスの専門家確認」を、決めたことに。
4. 18.7 の「5. 公開配布に向けた署名とインストーラ整備」を、カード 40〜47 への参照に。
5. PR はマージしない。本文に「承認待ち」と、変えた所の一覧を書く。

## 完了条件
- [ ] PR を出し、メンテナの承認でマージする

## 注意
- ライセンスの専門家の確認(SPEC 16 章の冒頭)が要るかは、メンテナに判断を頼む。案は docs/licenses.md の表のとおり。
