# 38. GPU のない PC では、長い読みに zenz-v2.5-small を使う

## 目的
GPU のない PC で、長い文が時間の上限に収まらず AI なしになるのを減らす(精度と待ち時間の両方)。

## 読むもの
- docs/adr/0024、0029
- `rewriter/lm_rewriter.cc` の `PrepareFor`・`RunPreconvert`・文全体の選択

## やること
- CPU で、読みが 12 文字より長ければ small、それ以下は品質の段階の zenz(medium)を使う。
- 先回りの変換の結果のキャッシュは、使ったモデルで区切る(`ModelKey`)。
- 起動時に両方読み込む。入力がないときは両方外す。

## 完了条件
- [x] CPU の AJIMEE が上がる(67.0 → 83.0%)、日常が下がらない(97.5%)
- [x] 打ってすぐ Space の正解と時間が良くなる(36 → 46、中央値 380 → 162 ms)
- [x] 負荷試験・単体テスト
- [x] docs/adr/0035

## 注意
- CPU の精度は PC の負荷で揺れる(時間の上限があるため)。比べるときは続けて測る。
- GPU で測った精度は、CPU の時間の上限の影響を含まない。GPU のない PC の評価は `KOTORI_LM_DEVICE=cpu` で。
