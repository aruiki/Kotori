# 20: タスクバーに入力モード(あ / A)を出す

- 仕様: 11.4、10.1(`ITfCompartment` 監視)
- 前提: 18
- 規模の目安: 350 行

## 目的
利用者の実機での報告と ATOK の調査から: 日本語入力のオン/オフが画面に出ないので、
半角/全角キーが効いたかどうか分からない。Windows 8 以降のタスクバーの入力インジケーターに
「あ」(オン)/「A」(オフ)を出し、クリックでも切り替えられるようにする。

## 手順
1. `mode_item.cpp`: `GUID_LBI_INPUTMODE` の言語バー項目(`ITfLangBarItemButton` と
   `ITfSource`)。アイコンは GDI で「あ」「A」を描いて作る。文字の色はタスクバーの配色
   (`SystemUsesLightTheme`)に合わせる。左クリックでオン/オフを切り替える。
2. `TextService` は `Activate` で項目を足し、`GUID_COMPARTMENT_KEYBOARD_OPENCLOSE` の
   変化(`ITfCompartmentEventSink`)で表示を描き直す。`Deactivate` で外す。
3. クリックで切り替えるとき入力中の文字があれば、コンポジションの入力欄に確定してから閉じる。

## 後続
- キャレット付近に「あ / A」を1秒出す表示(11.4)は、描画の方式を決めてから別の作業にする。

## テスト
- アイコンと言語バーは実機でしか確かめられない。windows の CI でビルドと登録・解除を確かめる。
