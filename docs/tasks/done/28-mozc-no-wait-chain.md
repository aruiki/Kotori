# 28: 要求どうしの待ちの積み重なりをなくす(GPU のない PC)

- 仕様: docs/adr/0029
- 前提: 27
- 規模の目安: パッチ 90 行

## 手順
1. 先回りの変換は、要求の最中・直後 150 ms はロックを取らず、変換した読みはやり直さない。
2. 前置きの計算を分けてやめられるようにする(`UsePrefix`)。
3. GPU がないとき、上限は要求の時点から、60 文字を超える読みは AI なし、文節ごとの並べ替えなし。
4. AI を使わない場面はロックの前に抜ける。

## テスト

- `eval_all.sh` の精度が変わらない。
