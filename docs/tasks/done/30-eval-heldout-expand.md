# 30: 最終評価用のセットを数百問に増やし、比較の手順を作る

- 仕様: docs/IMPROVEMENT_PROPOSALS.md の案 01・12、eval/README.md
- 前提: なし
- 規模の目安: データ 300 問、文書 50 行

## 目的
今の最終評価用のセット(120 問)では、1〜2 問の差を偶然と区別できない。分野ごとに数百問にし、信頼区間を出す。
Google 日本語入力・Microsoft IME と同じ条件で比べる手順も書く。

## 手順
1. eval/README.md の「許容する表記の基準」に従って、分野(仕事・チャット・技術・固有名詞・数字・ニュース)ごとに
   50 問ずつ足す。読みの誤りがないか、Mozc と Kotori の誤りを 1 問ずつ確かめる。
2. `eval_baseline.py` に Acc@1 の 95% 信頼区間(Wilson)を出す。
3. 他の IME と比べる手順(同じアプリ、同じ前の文、学習を切る、版を記録)を `eval/README.md` に書く。

## テスト
- 4 品質で評価し、分野ごとの結果と信頼区間を記録する。

- [ ] 300 問以上、分野ごと 50 問以上
- [ ] 調整に使っていないことを README に明記
