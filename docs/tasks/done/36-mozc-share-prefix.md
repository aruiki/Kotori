# 36. 生成の前置きを打鍵をまたいで使い回し、根どうしで共有する

## 目的
入力中の AI の計算(稼働率 47%)を、予測の当たりと変換の精度を変えずに減らす。

## 読むもの
- docs/adr/0024、0032
- `rewriter/zenz_scorer.cc` の `BeamSearch`・`UsePrefix`・`KeepPrefix`

## やること
- 複数の根のビームサーチでも、根 0 の前置きを前回から使い回す。ほかの根は根 0 と同じ先頭を写す。
- 前置きの残りと最後のトークンを 1 回の計算にまとめる。

## 完了条件
- [x] 稼働率が下がる(47.1% → 42.6%)
- [x] 予測の当たりと変換の精度が変わらない(`eval_predict.py`、`eval_all.sh`)
- [x] 負荷試験で異常終了なし、単体テストが通る
- [x] docs/adr/0033

## 注意
- 実験中にビルドしない。インストール先に zenz-medium がないと Low の評価が Mozc 単体と同じになる
  (古い版が入っているとき)。モデルと DLL を 1 つのフォルダに集めて `eval_all.sh` の 2 つ目の引数に渡す。
