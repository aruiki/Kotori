# 19: 取り消せる確定がないとき Ctrl+Backspace をアプリへ渡す

- 仕様: 9.4(REQ-9-5)、11.2
- 前提: なし
- 規模の目安: 20 行

## 目的
待機中の Ctrl+Backspace は確定アンドゥに割り当ててあるが、確定アンドゥはまだなく、キーを
飲み込むだけだった。そのためアプリの単語削除(Ctrl+Backspace)が効かなかった。REQ-9-5 は
「確定直後」だけの機能なので、取り消せる確定がないときはキーをアプリへ渡す。

## 手順
1. `Session::key` で、`UndoCommit` は取り消せる確定があるときだけコマンドとして扱う。
   確定アンドゥを入れるまでは常にアプリへ渡す。

## テスト
- session のテストに、待機中の Ctrl+Backspace を渡すことを足す。
