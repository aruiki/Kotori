# 26: AI が生成した文を文節に分け、ユーザー辞書の語を AI で変えない

- 仕様: docs/adr/0027(改善案 06・07)
- 前提: 25
- 規模の目安: パッチ 150 行

## 目的
生成した文で一語だけ違うとき、その文節だけ選び直せるようにする。ユーザー辞書に登録した表記を AI が変えない。

## 手順
1. `MatchesReading` に表記と読みの対応の出力を足す。
2. `SplitIntoSegments` で文節に分け、`CheckResizeSegmentsRequest` の切り直しに使う。
3. ユーザー辞書の語を含む 1 位の文・文節は、選び直し・当てはめ・並べ替えをしない。

## テスト
- `rewriter/lm_rewriter_test.cc`(区切り方、つながり、上限、空)。
- `eval_all.sh` の精度が変わらない。

## 完了条件
- [ ] CI(Mozc (Windows))が緑
- [ ] 実機で、生成した文の一語だけを選び直せること、ユーザー辞書の語が変わらないこと
